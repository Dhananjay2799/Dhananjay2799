## Featured work

### [FinCite — Consumer Finance RAG + Fine-Tuning](https://github.com/Dhananjay2799/fincite)

A working prototype that answers consumer-finance questions using retrieved CFPB guidance and a locally running language model.

- Built a repeatable ingestion pipeline and hybrid retrieval with Neon pgvector.
- Trained a Qwen3-1.7B LoRA adapter and recorded controlled base-versus-adapter comparisons.
- Converted the model to 4-bit GGUF for CPU inference and connected it to a Next.js interface.
- Documented retrieval results, model regressions, and evaluation limits instead of treating citations as proof of accuracy.

**Stack:** Next.js · TypeScript · Node.js · PostgreSQL · pgvector · Python · PyTorch · PEFT · llama.cpp
